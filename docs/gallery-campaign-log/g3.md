## Dossier-progress convention

One dossier per register item, one commit each, the table row flipped
PENDING → DONE (or GAP-RECORDED, with the gap stated precisely in the
dossier as NOT-OBTAINED + what would obtain it) in the same commit as
the dossier it describes. Per-dossier log entries append below (status,
one-line judgment calls, evidence gaps); a checkpoint summary
(complete / gap / remaining) at least every 5 dossiers. Evidence
gathered in this lane only (real `go run` probes, spec text quoted from
the pinned toolchain's `$GOROOT/doc/go_spec.html`, go1.26.5, read-only
code citations); anything requiring the web or a new toolchain is
recorded NOT-OBTAINED, honestly. The final product is the table above,
the dossier set, and a disposition-summary table (item → one-line
proposed disposition) — ready for a single user ruling session.
