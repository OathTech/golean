### The firing path

Membership/eval pins fire under the FULL differential
(`scripts/ci --diff` / the nightly `--slow`), not the fast gate —
so a toolchain bump is detected at the first full run after it, and
the baseline-diff step (`scripts/coverage-baseline-diff`) turns any
flip into a visible drifted-id list. The "no recorded run is a FAIL"
rule (CLAUDE.md, 2026-08-09) prevents the never-ran-it hole.
