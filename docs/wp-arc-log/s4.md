- JC-1 (Domain.lean): the ruled design's "table accessors" slot in
  `ScalarDom` is realized as the Q4 quit sites, NOT as dead accessor
  fields — v1 shared code consults tables nowhere (every consult site
  quits Q4 at BOTH instances; `SymState`/`State'` carries no tables,
  program-genericity by construction per the brief's own scope line),
  and shipping accessors no v1 code path calls would violate the
  fail-closed/no-inert-placeholder contract (CLAUDE.md). The accessor
  pair (`findFunc?`/`lookupTypeDef?`) is the recorded v2
  conditioned-facts lever (design OQ6 axis); adding it is additive to
  `ScalarDom`.
- JC-2 (Domain.lean): `ScalarDom` gains an `Atom : Type` field
  (design's `atom (i : Nat)` constructor generalized): symbolic
  instance `Atom := Nat` (the design's shape exactly), concrete
  instance `Atom := Empty` — which makes the drift embedding TOTAL
  (no atom case exists at the concrete instance) instead of partial.
  Pure mechanization of the design's intent; γ maps `atom i ↦ ρ.vals i`
  unchanged.
- JC-3 (ordering): the spike runs BEFORE the drift theorem's full
  walk, per the design's own schedule line (§6.2 "The mandatory early
  spike … before the drift theorem"; the phase brief numbers drift 3rd
  and the spike 4th as an inventory, but the gate exists to stop
  phase 1 before the expensive proof, so it must run first). The
  spike's guarded-fragment transport builds the same concretization +
  helper-commutation plumbing the drift walk reuses — nothing is
  thrown away on PASS, and on FAIL the drift cost is never sunk.
- JC-4 (Drift design): the drift theorem and the (phase-2) refinement
  step-commutation are proven as ONE generic walk over an
  interpretation pack (`Interp D` = intV/boolV/atomV + a `Sound`
  equation pack): the drift theorem is the instance at the concrete
  domain (equations close by `rfl`), the symbolic step-commutation is
  the instance at `γ_ρ` (equations = the design's ~25 scalar leaves).
  This is the lift-repeated-patterns lesson applied up front; the
  drift statement the charter names is still stated and gated as its
  own theorem (a corollary, in the default build).
- JC-5 (Mirror scope): conservative quits beyond the design table,
  each an honest "costs automation, never soundness" call, recorded in
  the `QuitSite` docstrings: (a) `Expr.recoverCall` quits Q6 (panic
