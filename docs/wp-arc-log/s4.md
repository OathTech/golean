quitting arms too, where the mirror deliberately carries no
information about what the machine does; the only equation available
there would be an equation between a quit and a real machine step,
which is either false or vacuous. So the theorem states exactly the
direction that has content — where the mirror computes, it computes
the machine — and the QUIT windows are pinned separately by the
`#guard`ed step counts (a computed check that the window really is
the length the transport assumes), not by this theorem.

Consequence for the drift gate, unchanged: an edit to any `stepFn` or
`stepFn'` COMPUTING arm that breaks agreement still fails the default
build. An edit that turns a computing arm into a quitting one does not
break this theorem — it breaks the `#guard`s of any window that
relied on it. Both are build failures; they are different build
failures, and the charter now says which is which.
